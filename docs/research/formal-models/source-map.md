## Scope of “all documents”

The inventory reads and hashes every available textual document found in the
mounted archives and standalone artifacts. Identical bytes are deduplicated;
archive aliases remain in the top-level list. It routes formal inputs versus
context/historical evidence. Git object databases and build directories are not
research documents and are excluded. This gives traceable inclusion without
pretending that every historical statement was independently fact-checked.

Current source content was not replaced by an archived tree. Existing modified
files were reconstructed from available verified baseline bytes and the fetched
GitHub comparison, then required to match current Git blob IDs exactly. The
delivery includes that six-file baseline and the resulting diff. A complete
current checkout and Rust toolchain are still required for project gates.
